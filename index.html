SECTION 1

Introduction to the Classical Cryptography Toolkit

The Classical Cryptography Toolkit is an educational software workbench developed for the Final Year Network Security curriculum (Electronics and Computer Engineering, 2026–2027).

Prior to modern computer-age ciphers such as AES (Advanced Encryption Standard) and RSA (Rivest-Shamir-Adleman), historical civilizations secured communications using pen-and-paper cryptographic methods. These algorithms operate primarily on the English alphabet of 26 letters through two canonical primitives: substitution (replacing characters) and transposition (rearranging characters).

Pedagogical Goal: Provide computer engineering students with hands-on insight into modular arithmetic modulo 26, linear matrix algebra, digraphic mechanics, permutation grids, and the mathematical roots of cryptology.
SECTION 2

What is Cryptography? Core Terminology

Cryptography is the science and mathematical study of protecting information by transforming it into an unintelligible format for unauthorized observers while enabling authorized recipients to reconstruct the original message.

Plaintext (P)

The original, human-readable message before any cryptographic transformation has taken place.

Ciphertext (C)

The scrambled, unreadable message produced by applying an encryption algorithm with a secret key.

Secret Key (K)

A specific parameter (shift integer, substitution permutation, keyword, or matrix) that governs the cryptographic transformation.

Encryption (E)

The mathematical process: C = E_K(P) that transforms plaintext into ciphertext.

Decryption (D)

The reverse mathematical process: P = D_K(C) that recovers plaintext using the matching key.

Cryptanalysis

The science of deducing plaintext or the secret key without prior knowledge of the key (codebreaking).

SECTION 3

Detailed Breakdown: Substitution Ciphers

In substitution ciphers, units of plaintext (individual letters or letter pairs) are substituted with different symbols according to a deterministic mapping.

1. Caesar Cipher (Shift Substitution)

Invented by Julius Caesar to protect military directives. Each letter is mapped to the letter k positions ahead in the modular alphabet.

Encryption: C = (P + k) mod 26
Decryption: P = (C - k + 26) mod 26

Keyspace: Only 25 non-trivial shifts (keys 1 through 25). Vulnerable to brute-force exhaust in seconds.

2. Monoalphabetic Substitution Cipher

Replaces each letter of the alphabet with a unique corresponding letter from an arbitrary 26-letter scrambled permutation key.

Mapping: Direct 1-to-1 permutation table (A → Q, B → W, C → E...)

Keyspace: 26! ≈ 4.03 × 1026 possible keys. While immune to brute-force exhaustion, it is completely trivial to crack via frequency analysis because the statistical frequency of single letters (E, T, A, O, I, N) is perfectly preserved.

3. Playfair Cipher (Digraphic Substitution)

Invented in 1854 by Charles Wheatstone and promoted by Lord Playfair. Encrypts digraphs (letter pairs) using a 5×5 key matrix generated from a keyword. 'I' and 'J' occupy the same cell.

Same Row: Shift right circular ((col + 1) mod 5)
Same Column: Shift down circular ((row + 1) mod 5)
Rectangle: Swap column coordinates with opposing corners

Text Normalization: Plaintext is grouped into 2-letter pairs. Duplicate letters in a pair are separated with filler 'X' (e.g. "BALLOON" → "BA LX LO ON"). Odd length is padded with 'X'.

4. Hill Cipher (Polygraphic Linear Algebra)

Developed in 1929 by Lester S. Hill. Treats blocks of letters as column vectors in modular arithmetic over GF(26) multiplied by an invertible n×n key matrix.

Encryption: C = (K × P) mod 26
Decryption: P = (K⁻¹ × C) mod 26
Invertibility Condition: gcd(det(K), 26) = 1

For a 2×2 matrix K = [[a, b], [c, d]], the determinant is ad - bc. The modular inverse of the determinant d⁻¹ is computed via the Extended Euclidean Algorithm. The inverse matrix is d⁻¹ × [[d, -b], [-c, a]] mod 26.

5. Vigenère Cipher (Polyalphabetic Cipher)

Published in 1586 by Blaise de Vigenère. Uses a keyword where each letter dictates a distinct Caesar shift value for corresponding plaintext characters.

Encryption: Cᵢ = (Pᵢ + Kᵢ) mod 26
Decryption: Pᵢ = (Cᵢ - Kᵢ + 26) mod 26

Historical reputation as "le chiffre indéchiffrable" (the indecipherable cipher) was broken in 1863 by Friedrich Kasiski using periodic repetition analysis (Kasiski examination) and later the Index of Coincidence (William Friedman).

6. One-Time Pad (Vernam Cipher)

Invented in 1917 by Gilbert Vernam and Joseph Mauborgne. Claude Shannon mathematically proved in 1949 that OTP achieves Perfect Secrecy (Information-Theoretic Security) if and only if:

  1. The key is truly uniformly random.
  2. The key is at least as long as the message.
  3. The key is kept strictly secret.
  4. The key is never reused (used exactly once and destroyed).

Demonstration Note: In this educational browser environment, keys are generated via crypto.getRandomValues() for learning. True physical OTP security depends on non-computational key distribution.

SECTION 4

Detailed Breakdown: Transposition Ciphers

1. Rail Fence Cipher (Zigzag Transposition)

Plaintext characters are written along imaginary diagonal "rails" in a downward and upward zigzag pattern. The ciphertext is formed by reading off each horizontal row sequentially.

Cycle Length = 2 × (rails - 1) for rails > 1

Preserves all unigram character frequencies. Readily broken through anagramming or automated frequency analysis of letter bigrams.

2. Columnar Transposition Cipher

Plaintext is written row-by-row into a grid whose width equals the length of a keyword. The columns are then read out vertically in the alphabetical order of the letters in the keyword.

Tie-Breaking Convention: For keywords with repeated characters (e.g. "APPLE"), identical letters are sorted left-to-right based on their initial column index, maintaining stable deterministic order.

SECTION 6

Key Management & Invertibility Guidelines

In all symmetric cryptosystems, both communicating parties must share the secret key beforehand. In classical cryptography, key validation is crucial:

  • Caesar: Any integer is acceptable; negative shifts or shifts > 25 are normalized via ((k % 26) + 26) % 26.
  • Monoalphabetic: Must contain exactly 26 distinct English alphabetic letters. Duplicate letters create ambiguous mappings that break decryption.
  • Hill Cipher Matrix: The 2×2 integer matrix [[k00, k01], [k10, k11]] must have gcd(determinant, 26) = 1. If determinant shares factors with 26 (i.e. divisible by 2 or 13), the matrix has no inverse modulo 26 and decryption is mathematically impossible!
  • One-Time Pad: The key must have at least as many alphabetic characters as the normalized input text. Short keys cannot be safely cycled without degrading to Vigenère.
SECTION 7

Security Limitations & Modern Cryptanalysis

CRITICAL CYBERSECURITY ADVISORY:
Classical cryptographic algorithms implemented in this toolkit are strictly for educational and historical instruction. They must NEVER be used to protect sensitive, personal, financial, or industrial data in production software.

Why Classical Ciphers Fail in the Modern Era:

  • Frequency Analysis: In English text, the letter 'E' appears ~12.7%, 'T' ~9.1%, 'A' ~8.2%. Monoalphabetic substitution preserves these statistical spikes identically, allowing automated solvers to recover plaintext in milliseconds.
  • Known-Plaintext Attacks on Hill Cipher: A cryptanalyst who knows just two 2-letter plaintext-ciphertext pairs can set up a system of linear equations to solve for the secret 2×2 key matrix in polynomial time.
  • Kasiski Examination & Index of Coincidence: Polyalphabetic ciphers like Vigenère reveal key length through repeated ciphertext trigrams, reducing the problem to parallel Caesar ciphers.
  • Small Keyspace: Modern symmetric encryption (AES-256) uses a 256-bit key (1.15 × 1077 possibilities). Classical ciphers have negligible keyspaces easily enumerated by commodity microprocessors.
SECTION 8

Frequently Asked Questions (FAQ)

Encryption transforms readable plaintext into obfuscated ciphertext using a secret key and mathematical algorithm. Decryption is the exact inverse mathematical operation that uses the corresponding key to reconstruct the original plaintext from the ciphertext.

Because classical algorithms are deterministic mathematical functions, supplying an incorrect key will simply evaluate to pseudo-random garbage characters rather than meaningful text. For algorithms requiring mathematical invertibility (such as Hill Cipher), an invalid key may fail modular inversion altogether.

Playfair operates strictly on digraphs (2-letter pairs) and forbids identical letters within the same digraph; it inserts 'X' between repeated letters and at the end of odd-length messages. Hill Cipher requires input length to be a multiple of the matrix dimension (2 for a 2×2 matrix); an odd trailing character must be padded with 'X' to form a valid 2×1 vector.

The English alphabet contains 26 letters, but a 5×5 grid accommodates exactly 25 symbols. Historically, 'I' and 'J' were combined into a single matrix cell (or 'Q' was omitted) because 'I' and 'J' share historical Latin roots and human readers can readily disambiguate words based on context during decryption.

Classical ciphers operate on single or small groups of alphabet characters without complex non-linear S-boxes, diffusion layers, or large cryptographic keyspaces. Modern computers can analyze statistical correlations, calculate modular linear systems, or execute exhaustive searches in fractions of a millisecond.

Shannon's proof of Perfect Secrecy dictates that uncertainty (entropy) of the key must equal or exceed uncertainty of the message. If the key is shorter and repeated, the cipher collapses into a polyalphabetic Vigenère cipher with periodic vulnerabilities.
